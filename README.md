# SubsAnywhere — версия 0.3.3

Расширение выводит две дорожки субтитров одновременно. Можно сочетать:

- две встроенные дорожки плеера;
- встроенную дорожку и свой файл SRT;
- два добавленных SRT-файла.

Для каждой строки выбирается отдельное положение. У добавленных SRT есть ручная синхронизация по времени.
Собственные субтитры остаются видимыми, когда плеер развёрнут на весь экран.

## Первая установка

1. Используйте постоянную папку `/Users/itsme/Sites/subs-anywhare`.
2. Откройте Chrome → `chrome://extensions`.
3. Включите **Developer mode** («Режим разработчика»).
4. Нажмите **Load unpacked** («Загрузить распакованное расширение»).
5. Выберите папку `/Users/itsme/Sites/subs-anywhare`.
6. Откройте страницу с видео и запустите ролик.
7. Нажмите значок расширения → **«Подключить к плееру»** → разрешите доступ.
8. Выберите нужный плеер.

## Как добавить готовый SRT

1. В окне расширения найдите раздел **«Мои субтитры»**.
2. Нажмите **«Добавить SRT»** и выберите файл.
3. Он появится в списках «Субтитры 1» и «Субтитры 2» в отдельной группе **«Добавленные SRT-файлы»**.
4. Выберите этот файл в одном из двух списков.

Файл и его настройки сохраняются внутри Chrome. Поддерживаются UTF-8 и Windows-1251. Максимальный размер файла — 5 МБ.

## Синхронизация

В разделе **«Синхронизация»** выберите добавленный файл.

- отрицательное смещение показывает субтитры раньше;
- положительное смещение показывает их позже;
- кнопки `−5`, `−1`, `−0,1`, `+0,1`, `+1`, `+5` позволяют быстро подстроить время;
- точное значение можно напечатать в поле «Смещение, секунд».

Пример: если фраза появляется на 2 секунды раньше речи, установите `+2.0` — субтитры будут показаны позже.

## Как обновить уже установленную версию

Изменения файлов **не всегда подхватываются Chrome сразу**.

1. Откройте `chrome://extensions`.
2. Найдите «SubsAnywhere» и нажмите кнопку **Reload** («Обновить», значок круговой стрелки).
3. Перезагрузите страницу с видео обычным `Cmd+R` / `Ctrl+R`.
4. Снова откройте расширение. Подключение к ранее выбранному плееру восстановится автоматически, если Chrome уже дал доступ к странице.

Удалять расширение и добавлять его заново не нужно. Если выбрать другую папку, Chrome воспримет её как отдельную копию.

Версия 0.3.3 хранит настройки централизованно, не перезаписывает их при простом открытии окна, восстанавливает выбранный плеер после перезапуска служебного процесса Chrome, корректно переподключается при замене видео, `iframe` или встроенной дорожки после смены озвучки, поддерживает полноэкранный режим и позднюю загрузку встроенных дорожек.

## Ограничения

- Поддерживается постоянное смещение всей дорожки. Если субтитры постепенно «уезжают» всё сильнее, это уже разница скорости/частоты кадров; для неё потребуется отдельная функция растяжения времени.
- Впаянные в видео субтитры прочитать нельзя.
- Расширение работает с одним выбранным плеером за раз, чтобы три плеера на странице не мешали друг другу.
