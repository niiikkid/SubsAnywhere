# SubsAnywhere — версия 0.6.0

Расширение подключается к HTML-видеоплееру, показывает **одну оригинальную дорожку субтитров** и делает её слова и выражения кликабельными для перевода через DeepSeek.

## Как пользоваться

1. Откройте страницу с видео и запустите его.
2. Нажмите значок расширения.
3. Нажмите **«Подключить к плееру»** и разрешите доступ к странице.
4. Выберите встроенную оригинальную дорожку.
5. Выберите модель: **DeepSeek V4 Flash** (быстрее и дешевле) или **DeepSeek V4 Pro**.
6. Сохраните API-ключ DeepSeek.
7. Нажмите на подчёркнутое слово или выражение в субтитрах.

Если после смены звуковой дорожки плеер заново создал субтитры, нажмите **«Перезапустить поиск субтитров»**. Расширение заново найдёт плеер и применит к нему сохранённый выбор субтитров.

Над выбранным фрагментом появится короткая подсказка:

- **Обычно** — 2–3 распространённых варианта перевода;
- **Здесь** — перевод в текущем контексте.

Подсказка закрывается крестиком или повторным нажатием на тот же фрагмент.

## Что отправляется в DeepSeek

Для кликабельного перевода отправляется только текущая реплика на экране, максимум 500 символов. Целый файл субтитров не отправляется.

Ограничения расходов:

- один запрос за раз;
- минимум 750 мс между запросами;
- одинаковая реплика повторно не отправляется;
- кэш до 80 реплик;
- максимум 120 запросов за одну загрузку страницы;
- ответ до 400 токенов;
- режим размышлений модели отключён.

API-ключ хранится локально внутри расширения и не передаётся странице с видео.

## Свой SRT

Если нужной встроенной дорожки нет:

1. В разделе **«Свой SRT»** нажмите **«Добавить SRT»**.
2. Выберите файл оригинальных субтитров.
3. При необходимости настройте смещение и скорость вручную.

Поддерживаются UTF-8 и Windows-1251. Максимальный размер файла — 5 МБ.

## Настройки страницы

Отдельно для каждой страницы сохраняются:

- выбранный плеер;
- оригинальная дорожка;
- добавленные SRT-файлы;
- положение и размер текста;
- ручное смещение и скорость.

При переходе на другую страницу старые субтитры отключаются. API-ключ и выбранная модель DeepSeek общие для всего расширения.

## Установка и обновление

Постоянная папка расширения:

`/Users/itsme/Sites/subs-anywhare`

После изменений:

1. Откройте `chrome://extensions`.
2. Найдите **SubsAnywhere** и нажмите **Reload**.
3. Обновите страницу с видео.
4. Снова нажмите **«Подключить к плееру»**.

Переустанавливать расширение и делать ZIP не нужно.

## Ограничения

- Впаянные в изображение субтитры прочитать нельзя.
- Плеер должен использовать обычный HTML `<video>` и текстовые дорожки.
- Перевод по клику требует собственного API-ключа DeepSeek.
